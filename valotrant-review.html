I built **ZoneSync** because I love listening to music while playing competitive 5v5 games, but I constantly missed critical audio cues like enemy footsteps. Alt-tabbing to lower the volume or manually pausing tracks was distracting and often got me killed. **ZoneSync** solves this by automatically adjusting the volume of your background apps (Spotify, Discord, Opera, etc.) based on real-time game events. ## Features (with clickable videos) ## Features - **Dynamic Volume Control:** Automatically ducks volume during important gameplay moments. - **Context-Aware:** - **Walking:** Lowers volume when you hold your Walk key (e.g., Shift). [![Video Title](https://img.youtube.com/vi/nGo2iRFJits/0.jpg)](https://www.youtube.com/watch?v=nGo2iRFJits) - **Clutch Mode:** Automatically lowers volume when you are the **last player alive** (1vX situations). - **Death Mode:** Restores volume when you die. - **Round & Buy Phase:** Custom volume levels for active combat vs. shopping time. [![Video Title](https://img.youtube.com/vi/rhAbj9WUvik/0.jpg)](https://www.youtube.com/watch?v=rhAbj9WUvik) - **Testing:** test the volume of each situation to fine tune before a match. - **App Mixer:** choose exactly which apps you want to control (e.g., mute Spotify but keep Discord normal).     Overview

    What is live today, and what is being proposed.

    Live today

    ZoneSync is published on the Overwolf Store and currently supports Counter-Strike 2 only. The live app is unmodified VALORANT-wise: it does not detect VALORANT, install in it, or change any audio while VALORANT is running.

    Proposed for VALORANT

    The same five volume behaviours that ship for CS2, driven by VALORANT's round and player-state events. The user experience is identical; only the event source differs.

    What we are asking for

    Permission to publish a VALORANT build on the Overwolf Store, and confirmation that the behaviours below are acceptable for competitive play.

    Clips

    Recordings of the app reacting to live gameplay. Each clip was captured with VALORANT running and the ZoneSync overlay active.

    Walking detection

    Music drops to the reduced level while the walk key is held and returns on release. No overlay is drawn over the game.

    Round & buy phase volumes

    Separate user-defined levels for the buy phase and for active combat, switched on round transition.

    App Mixer

    The user picks which applications ZoneSync is allowed to control. Game audio is never in that list.

    Event mapping

    Every input the app would read from VALORANT, and the only action it would take. All five behaviours are already live in the CS2 build.

    Game event ZoneSync action Effect on the player Effect on the game
    Walk key held Lower the volume of user-selected apps to the configured reduced level. Music fades down while moving quietly, restores on release. None. Audio only, no input is sent to the game.
    Buy phase start Switch user-selected apps to the configured buy-phase level. Quieter music while shopping, so team comms stay clear. None.
    Round live Switch user-selected apps to the configured combat level. Music stays low for the whole round. None.
    Player death Restore the user's normal volume level. Music comes back up while dead or spectating. None. No respawn or input timing is affected.
    Last player alive Apply the configured clutch level for the duration of the round. Quietest setting for 1vX situations. None. Derived from a round-state event, not from screen analysis.

    Competitive integrity

    An explicit list of what the app does and does not do.

    What ZoneSync does

    • Read game state events locally through the Overwolf Game Events Provider.
    • Change the Windows per-application audio volume of apps the user explicitly selected.
    • Show its own settings window and status indicator outside the game viewport.
    • Store its settings locally on the user's machine.

    What ZoneSync never does

    • No reading or parsing of the game's process memory.
    • No aim assistance, recoil control, trigger automation or any input injection.
    • No capture, screenshotting, streaming or replay of game content.
    • No overlay drawn on top of the game viewport.
    • No modification of game files, memory or network traffic.
    • No collection or transmission of gameplay data, user data or analytics.
    • No access to the game's own audio output.

    Data & permissions

    ZoneSync runs entirely on the user's machine. There is no account, no server and no network traffic.

    What is read

    Round phase transitions, the player's alive/dead state, whether the player is the last one alive, and whether the walk key is currently held. Nothing else is read from the game.

    What is controlled

    Only the per-app audio sessions the user ticks in the App Mixer. Game audio is never controlled and the game's own volume settings are never modified.

    What leaves the device

    Nothing. No analytics, no crash reporting, no telemetry, no account. The app makes no outbound network requests, so there is no player data to leak.

    Review questions

    If any of the behaviours described here is not acceptable for competitive play, or if additional detail is needed on how an event is detected, please get in touch and we will provide the specifics.
